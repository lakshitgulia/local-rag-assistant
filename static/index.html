About this view

These numbers are read live from the incremental-ingestion index (index/manifest.json, index/chunks.json) and the background watcher's own status file — not a fixed snapshot. "Last watcher update" only appears once the watcher has actually processed a file since it last started; it's left unavailable, not guessed, until then.
